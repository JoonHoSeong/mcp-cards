## What is NemoClaw for Hermes Agents?

NVIDIA NemoClaw is an open source blueprint for running autonomous agents in enterprise environments. NemoClaw for Hermes Agents helps teams deploy Hermes agents that work with approved tools and data sources, learn preferred workflows from real usage, and turn repeatable guidance into durable Hermes Skills.

With NemoClaw, Hermes Agents are installed with the [NVIDIA OpenShell](https://build.nvidia.com/openshell) runtime to add policy-based privacy and security guardrails, giving users more control over their agents' behavior and data handling. OpenShell is currently available in early preview.

With NemoClaw, Hermes can join shared team environments, help with tasks such as pull request review, incident triage, product planning, and launch review, then apply what it learns the next time similar work appears. The result is an adaptive agent experience that gets better as teams use it.

## Why NemoClaw
![Details about NemoClaw](https://assets.ngc.nvidia.com/products/api-catalog/nemoclaw/nemoclaw-for-hermes-agent/benefits.png)

- Team learning: Capture how your team works from everyday interaction, corrections, and feedback.
- Reusable Hermes Skills: Turn repeatable workflows, preferred formats, tool patterns, and expert guidance into durable skills.
- Approved tools and data: Connect Hermes to the systems teams already use, with enterprise controls over access and behavior.
- Better future work: Apply learned skills to future requests so teams get more consistent, higher-quality results over time.

## Example NemoClaw Workflow for Hermes Agents
![Details about NemoClaw](https://assets.ngc.nvidia.com/products/api-catalog/nemoclaw/nemoclaw-for-hermes-agent/workflow.png)

1. A team works with Hermes in a shared environment.
2. Hermes uses approved tools and data sources to help with the task.
3. Team members correct, refine, and teach Hermes their preferred approach.
4. Hermes captures repeated guidance as Hermes Skills.
5. Future requests improve as Hermes applies those skills and turns team expertise into reusable AI capability.
