## What is NVIDIA NemoClaw?

NVIDIA NemoClaw is an open source reference stack that simplifies running OpenClaw always-on assistants with a single command. It installs the [NVIDIA OpenShell](https://build.nvidia.com/openshell) runtime to add policy-based privacy and security guardrails, giving users more control over their agents' behavior and data handling.

NemoClaw and OpenShell are currently available in early preview.

NemoClaw uses open source models, like NVIDIA Nemotron, alongside the [NVIDIA OpenShell](https://build.nvidia.com/openshell) runtime, a secure environment designed for executing claws more safely. By combining powerful open source models with built-in guardrails, NemoClaw helps simplify and strengthen the way organizations deploy AI agents.

## Why You Need NemoClaw

![Details about NemoClaw](https://assets.ngc.nvidia.com/products/api-catalog/nemoclaw/nemoclaw-for-openclaw/benefits.png)

- One-command setup: Install the OpenShell runtime, open models, and tools to run always-on agents.
- Built-in safeguards: Apply OpenShell configurable controls for privacy, security, and policy compliance.
- AI-powered workflows: Use Nemotron and other open models to handle reasoning and task automation.
- Flexible execution: Run long-running agents locally, on cloud, or on enterprise hardware with full control.
